# Custom Tools Mod

Enhance your Minecraft mining experience with custom tools and blocks.

## Features

- Adds custom pickaxes with different mining levels
- Includes a custom mining platform block

## Requirements

- Minecraft 1.20.4
- Fabric Loader 0.14.0 or later
- Fabric API

## Installation

1. Download the mod JAR file.
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

- Craft or obtain the custom pickaxes from the game.
- Use the custom pickaxes to mine blocks on the custom mining platform.

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
